- **[Bettbox](https://github.com/appshubcc/Bettbox)** · Высокий рост, Новичок — Новый проект (ноябрь 2025), поддерживает HarmonyOS и ТВ; за 90 дней звёзд стало почти вдвое больше

- **[Loon](https://apps.apple.com/us/app/id1373567447)** (App Store) · Быстрый рост — Число оценок выросло на 4,0% за 7 дней. Богатая экосистема плагинов; поддерживает VLESS, Hysteria2 и др.
